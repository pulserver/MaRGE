MaRGE on pulserver's virtual scanner

This page is MaRGE. pulserver, which designs, simulates and reconstructs each scan, runs in Docker on this computer, and a small helper keeps it installed, up to date and configured with the scanner below.

Status

The helper is a Python script that needs nothing but Python 3.8 or newer. Download it and run it; it opens this page again and stays in its window while the page is in use.

Download the helper python pulserver-local.py

Or, without the helper, start pulserver with Docker's default scanner:

Your plugins

      reconstruction plugins, <name>.py.
      MaRGE's sequence list offers your sequences beside pulserver's, and a file of
      the same name as one of pulserver's takes its place.
