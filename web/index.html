MaRGE on pulserver's virtual scanner

This page is MaRGE. pulserver, which designs, simulates and reconstructs each scan, runs in Docker on this computer, started by a launcher downloaded from this page with the scanner settings below.

Status

When the browser asks whether this page may connect to devices on the local network, allow it: pulserver is such a device.

Start pulserver

The launcher checks that Docker is installed and running, downloads pulserver's image when it is not on this computer, updates it when a newer version is published, and starts it with the scanner below, then opens this page. Run it again after changing the scanner, or to update pulserver.

then double-click pulserver.bat.

then run it from a terminal in the download folder; macOS and Linux do not run a downloaded script by double-clicking it:

sh pulserver.sh

Your plugins

Directories on this computer holding your own scanner-sequence plugins and reconstruction plugins, <name>.py. MaRGE's sequence list offers your sequences beside pulserver's, and a file of the same name as one of pulserver's takes its place.
